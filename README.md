# EMG gesture classification and replay
Author: Oluwaferanmi Esther Onifade

MATLAB workflow for recorded EMG inspection, feature extraction, classifier training and comparison, model selection, and recorded-signal replay. This is offline classification and replay; it does not control a physical prosthesis.

## Setup and run
Requires MATLAB and Statistics and Machine Learning Toolbox. Obtain the matching S1_E1_A1.mat recording with emg, restimulus, and rerepetition fields under the dataset's access terms and place it in data/. Scripts assume 2000 Hz sampling; confirm your recording matches.

Run the six scripts in scripts/ in numerical order. Later scripts load models generated by earlier steps. Exported source replaces PC-specific paths with project-relative paths. Raw recordings and fitted models are excluded.

No new accuracy claim or physical prosthetic validation is made by this export.
